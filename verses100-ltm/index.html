About this palace
One road through Bible lands, one district per topic and one room per passage, following the list in Robert J. Morgan’s 100 Bible Verses Everyone Should Know by Heart. Some passages run a few verses longer than the book’s reference so each thought is complete.
The places are simplified or imagined so each room is easy to remember. The synagogue follows the one in the James palace; the tabernacle’s proportions follow Exodus 26–27.
