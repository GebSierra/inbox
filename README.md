# inbox

A catchall for small projects.

| Folder | What it is |
| --- | --- |
| [dangerous-preaching](dangerous-preaching/) | Sermon practice. Keep talking until the timer ends, or the run is lost. Records your voice, holds a pasted transcript, and keeps an ideas pad. |
| [tuning-room](tuning-room/) | Singing practice. Pitch drills with the screen fading out, warm-ups, hymn lines, song practice, and a weekly check. Use Chrome and wired headphones. |
| [tabernacle-ltm](tabernacle-ltm/) | Hebrews in the Tabernacle: a memory palace for the outline of Hebrews, a companion to the book [*The Chapter Code*](https://a.co/d/04W9GCw3). Thirteen chapters at thirteen places in the tabernacle, walkable in 3D and built to the cubit from Exodus, with the camp of Israel round it. Uses the shared `ltm-engine`. |
| [som-ltm](som-ltm/) | The Sermon on the Mount (Matthew 5–7) on a hillside above the Sea of Galilee. Prototype: Matthew 5:1–20 on the summit (the Seat, the Sheepfold, the Lookout, the Threshing Floor). Switch between five-verse rooms and the sermon's outline sections in the "i" panel; uses the shared `ltm-engine`. |
| [verses100-ltm](verses100-ltm/) | The 100 Bible Verses palace: one road from Genesis 1:1 to Revelation 22:20, one district per topic, one room per passage. Districts 1–5 built (rooms 1–19: Beginnings to Assurance); see `PLAN.md` and `INSTRUCTIONS.md`. Uses the shared `ltm-engine` in its new passage mode. |
| [my-place](my-place/) | A walkable 3D alpine gorge: river rapids, a misty waterfall and fir forest. On-screen joystick or WASD, drag to look. |
