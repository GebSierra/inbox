# inbox

A catchall for small projects.

| Folder | What it is |
| --- | --- |
| [keep-preaching](keep-preaching/) | Sermon practice. Keep talking until the timer ends, or the run is lost. Records your voice, holds a pasted transcript, and keeps an ideas pad. |
| [tuning-room](tuning-room/) | Singing practice. Pitch drills with the screen fading out, warm-ups, hymn lines, song practice, and a weekly check. Use Chrome and wired headphones. |
| [tabernacle-ltm](tabernacle-ltm/) | The tabernacle in the wilderness, walkable in 3D and built to the cubit from Exodus, with the camp of Israel round it. Free roam; uses the shared `ltm-engine`. |
| [my-place](my-place/) | A walkable 3D alpine gorge: river rapids, a misty waterfall and fir forest. On-screen joystick or WASD, drag to look. |
