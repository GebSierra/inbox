# The owner's corrections, written as rules

Every correction the owner made during the Colossae build, quoted from their own messages, sorted by category. **T** = enforced by a test, **V** = enforced by the book validator, **R** = a review item.

| Rule | Owner's words | Check |
|---|---|---|

| Order: 1 near-left, 2 far-left, 3 far-right, 4 near-right, 5 centre | "I start in the bottom left then move up the left hand side" | T: clockwise on screen |
| The 5th spot sits at the centre of the square, not on an object | "don't put the 5th one on a crate put it in the center of the square of markers" | T: centre inside the square |
| Rooms run clockwise: entrance-left first, up the left, down the right | the owner's chapter 1 sketch | V and R |
| Gates and wells can be rooms; not every spot needs a distinct object | "Its ok that not all 5 sublocations have a distinct object" | — |
| Rote first: 10–20 readings before using locations | "say each verse 10-20 times" | R (tutorial) |
| Learners make their own images; show examples only for the first verse or two | "encouraging people to create images for themselves" | R |
| ESV text | "We will use the ESV" | V |
| Keep the rooms the owner placed; remove the least interesting extras | "remove two stalls... keep the pomegranate stall" | R |
